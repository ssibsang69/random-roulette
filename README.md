# 🎯 오늘의 운명 룰렛 (Today's Destiny Roulette)

> **친구들과 함께하는 공정하고 신나는 랜덤 룰렛 추첨 웹 애플리케이션**  
> *기말 과제 제출용 웹 프로젝트*

---

## 📌 1. 프로젝트 개요

- **프로젝트명**: 오늘의 운명 룰렛
- **개발 목적**: 친구들과 밥값 내기, 설거지 당번, 벌칙 정하기, 커피 쏘기 등 일상에서 발생하는 선택의 순간을 공정하고 즐겁게 해결하기 위한 인터랙티브 웹사이트
- **핵심 특징**:
  - 단순한 이름 텍스트 출력 방식이 아닌, **실제 Canvas 물리 감속 애니메이션으로 회전하는 룰렛** 구현
  - **12시 상단 고정 포인터와 100% 일치**하는 정밀 역산 수학 알고리즘 적용
  - 경쾌한 효과음(Tick Sound)과 당첨 팡파레(Web Audio API 자체 생성)
  - 은은하게 흩날리는 색종이(Confetti) 축하 연출
  - 복잡한 빌드 도구나 무거운 외부 라이브러리 없이 **순수 HTML5, CSS3, JavaScript(ES6+)**로 구현하여 어떤 브라우저에서도 즉시 실행 가능

---

## 🎨 2. 디자인 방향 및 시스템

- **배경**: 눈이 편안하고 깔끔한 화이트 / 라이트 그레이 계열 (`#F8F9FC`)
- **포인트 컬러**:
  - **Primary**: 세련된 퍼플 (`#6C5CE7`, `#7C3AED`)
  - **Secondary / Accent**: 경쾌한 옐로우 / 앰버 (`#FFD166`, `#F59E0B`)
  - **Pointer**: 높은 시인성의 루비 레드 (`#E11D48`)
- **타이포그래피**: 현대적이고 가독성이 뛰어난 한국어 폰트 (Pretendard & Noto Sans KR)
- **레이아웃**:
  - **PC 화면**: 좌측(참가자 관리 영역)과 우측(룰렛 및 결과 발표 영역)의 2단 그리드
  - **모바일 화면**: 터치하기 편한 반응형 1단 레이아웃
- **UI 감성**: 과도한 그라데이션과 불필요한 그림자를 배제하고, 깔끔한 카드(Card)와 둥근 모서리(Border Radius)를 적용한 모던 클린 & 프렌들리 테마

## ⚙️ 3. 핵심 기능 및 기술 구현

### 1) 참가자 관리 (좌측 카드)
- **이름 입력 & 추가**: 마우스 클릭 및 `Enter` 키 입력 지원
- **실시간 유효성 검사**:
  - 공백 및 빈 값 입력 방지 안내
  - 중복 이름 등록 방지 및 알림 안내
  - 12자 글자 수 제한 안내
- **참가자 수 실시간 카운트 배지**
- **개별 삭제 및 전체 초기화**:
  - 참가자별 원클릭 삭제 버튼
  - 전체 초기화 시 사용자 실수 방지를 위한 **안내 모달(Modal)** 제공
- **최소 인원 안내**: 2명 미만 시 추첨 버튼 비활성화 및 안내 문구 노출
- **예시 불러오기**: 첫 실행 시 편리하게 테스트할 수 있는 '예시 친구들(민수, 지우, 서연, 현우)' 원클릭 불러오기

### 2) 메인 룰렛 및 물리 회전 엔진 (`roulette.js`)
- **HTML5 Canvas 기반 벡터 렌더링**:
  - Retina/HiDPI 디스플레이(`window.devicePixelRatio`) 선명도 대응
  - 참가자 수에 따른 섹터 분할 및 12가지 파스텔-비비드 색상 자동 매핑
  - 참가자 이름 길이에 따른 폰트 크기 자동 조절 및 말줄임(`…`) 처리
- **정밀한 각도 역산 수학 알고리즘**:
  1. `Math.random()`으로 참가자 중 공정하게 당첨자 인덱스 $i$ 결정
  2. 당첨자 섹터 중심각 $\theta_{\text{mid}} = (i + 0.5) \cdot \frac{2\pi}{N}$
  3. 12시 고정 포인터 각도 $\theta_{\text{pointer}} = \frac{3\pi}{2}$ (270도)
  4. 목표 정지 각도 $\theta_{\text{target}} \equiv \theta_{\text{pointer}} - \theta_{\text{mid}} \pmod{2\pi}$
  5. 6바퀴 이상의 박진감 넘치는 회전 후 **포인터가 가리키는 대상과 당첨자가 100% 일치**
- **Quartic Ease-Out 감속 애니메이션**:
  - $f(t) = 1 - (1 - t)^4$ (약 3.8초 지속)
  - 초반에는 빠르고 부드럽게 돌다가 서서히 멈추며 긴장감 고조
- **인터랙션 잠금(Locking)**:
  - 룰렛이 회전하는 동안 추첨 버튼, 입력창, 삭제/초기화 버튼을 자동 비활성화하여 조작 꼬임 원천 차단

### 3) 당첨 결과 및 축하 연출
- 회전이 멈춘 직후 결과 카드에 당첨자 이름(예: `🎉 민수 🎉`) 강조 표시
- 일상 속 재미를 더하는 위트 있는 맞춤 문구 (밥값, 설거지, 커피 쏘기 등)
- **자체 Canvas 파티클 색종이(`confetti.js`)**: 외부 라이브러리 없이 2.5초간 은은하게 떨어지는 경량 애니메이션
- **Web Audio API 사운드(`audio.js`)**:
  - 룰렛 회전 시 섹터를 지날 때마다 발생하는 '틱' 소리
  - 당첨 순간 울려 퍼지는 3화음 차임벨
  - 음소거 ON/OFF 토글 버튼 제공

### 4) 다시 추첨하기 및 히스토리 기록
- '한 번 더 추첨하기' 버튼으로 참가자 목록 유지 상태에서 즉시 재추첨
- 최근 추첨 결과 5건의 당첨자 및 시간 기록 표시

## 🚀 5. 실행 및 테스트 방법

### 방법 1: 브라우저에서 직접 열기 (설치 불필요)
- `index.html` 파일을 더블클릭하거나 크롬/엣지/웨일/사파리 등의 브라우저로 드래그 앤 드롭하여 바로 실행할 수 있습니다.

### 방법 2: 로컬 웹 서버 실행 (VS Code Live Server 등)
- Python 내장 서버:
  ```bash
  python -m http.server 8080
  ```
- Node.js `npx serve`:
  ```bash
  npx serve .
  ```
- 브라우저에서 `http://localhost:8080` 접속

## ✅ 6. 예외 상황 처리 및 테스트 완료 목록

1. ✔️ **참가자가 0명 또는 1명인 경우**: 추첨 버튼 자동 비활성화, 안내 문구 표시
2. ✔️ **이름 입력창이 비어있거나 공백인 경우**: 경고 안내 메시지 노출 및 입력 포커스
3. ✔️ **동일한 이름을 반복 입력하는 경우**: 중복 방지 알림 표시 및 추가 차단
4. ✔️ **이름이 길거나 참가자가 많은 경우**: 글자 크기 자동 조정 및 말줄임 처리
5. ✔️ **추첨 버튼을 연타하는 경우**: 회전 중 비활성화로 1회만 정상 실행
6. ✔️ **회전 중 삭제/초기화 시도**: 회전 중 모든 편집 버튼 잠금 처리
7. ✔️ **전체 초기화 시**: 확인 모달로 실수 방지 및 깔끔한 초기 상태 복구
8. ✔️ **모바일 화면 확인**: 320px~768px 너비에서도 요소 겹침 없이 완벽하게 반응형 렌더링
